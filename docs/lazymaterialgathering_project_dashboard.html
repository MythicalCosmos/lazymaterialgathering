5. Architecture map

Expected workflow

  1. Input: load a schematic and count required blocks.
  2. Planning: resolve recipes and raw materials; compare inventory.
  3. Gather: choose resource sources and direct Baritone.
  4. Process: smelt, blast, or smoke required materials.
  5. Craft: craft intermediate and final items.
  6. Verify: compare inventory with target quantities and recover from gaps.

The code contains a pipeline coordinator for this flow. A fully successful end-to-end run has not been demonstrated in the reviewed evidence.

Main code areas

  • Planning/calculation: RawMaterials, GatheringPlanner, CraftingPlanner, ProcessingPlanner, recipe helpers.
  • Execution: MaterialPipelineCoordinator, GatheringCoordinator, ProcessingCoordinator, CraftingCoordinator.
  • World knowledge: WorldKnowledge, biome/section scanning, resource location scoring, exploration targets.
  • UI: main/settings screens, material lists, pipeline controls, and debug screens.
  • Data/build: Python data-generation scripts, JSON resources, Gradle/Fabric configuration.
